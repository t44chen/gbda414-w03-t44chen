# GBDA 414 Week 3 FaceMesh Starter

This repository is the starter project for the GBDA 414 Week 3
technical workshop.

The project uses p5.js and ml5.js FaceMesh to detect facial
landmarks and draw a coloured shape over each eye.

## Student change

Open `sketch.js` and find:

```javascript
// CHANGE ONLY THE COLOUR BELOW
let maskColour = "#ff2bd6";
```

Replace the colour value with another hexadecimal colour.

Do not change the FaceMesh options, facial-part names, or drawing
functions during this workshop.

## Running the project

The published project requires:

- A laptop or desktop computer with a webcam
- A current web browser
- Permission to access the camera
- A reasonably well-lit face within the camera frame

## Libraries

- [p5.js](https://p5js.org/)
- [ml5.js](https://ml5js.org/)
